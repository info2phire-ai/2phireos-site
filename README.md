# 2phireOS website

This folder contains a simple static website for the 2phireOS TikTok Developer application.

## Files

- `index.html` — main website
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `style.css` — design

## Publish with GitHub Pages

1. Sign in to GitHub.
2. Click **New repository**.
3. Name it `2phireos-site`.
4. Set it to **Public**.
5. Click **Create repository**.
6. Click **uploading an existing file**.
7. Upload all four website files from this folder.
8. Click **Commit changes**.
9. Open the repository's **Settings**.
10. Select **Pages** in the left menu.
11. Under **Build and deployment**, choose **Deploy from a branch**.
12. Select branch `main` and folder `/ (root)`.
13. Click **Save**.
14. Wait a few minutes.

Your URLs should be:

- Website: `https://info2phire-ai.github.io/2phireos-site/`
- Privacy: `https://info2phire-ai.github.io/2phireos-site/privacy.html`
- Terms: `https://info2phire-ai.github.io/2phireos-site/terms.html`
